# R0001: heap-leak

The heap trace found memory still allocated at exit, so the test fails.

## Failing example

```pascal
procedure WriteOnce(const Path: string);
var
  Stream: TFileStream;
  Data: Byte;
begin
  Data := $2A;
  Stream := TFileStream.Create(Path, fmCreate);
  Stream.WriteBuffer(Data, 1);   // never freed
end;
```

## Fixed example

```pascal
procedure WriteOnce(const Path: string);
var
  Stream: TFileStream;
  Data: Byte;
begin
  Data := $2A;
  Stream := TFileStream.Create(Path, fmCreate);
  try
    Stream.WriteBuffer(Data, 1);
  finally
    Stream.Free;
  end;
end;
```

## Rationale

Nothing frees the stream, so heaptrc reports the bytes allocated at the
`TFileStream.Create` line — the runtime counterpart to P0501.

## Silencing it

`{@allow(R0001, reason: "...")}` is legitimate for a deliberate process-lifetime
allocation; otherwise free it on every path.
