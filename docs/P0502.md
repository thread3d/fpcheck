# P0502: double-free

An `{@owned}` value is freed a second time, or freed after its ownership was
transferred. The related span points at the first free.

## Failing example

```pascal
procedure TSocket.Close;
begin
  Free;   // destroys the instance and invalidates the caller's reference
end;

begin
  Sock := TSocket.Create;
  Sock.Close;
  Sock.Free;   // frees the same instance again
end;
```

## Fixed example

```pascal
procedure TSocket.Close;
begin
  // release the underlying handle only; the owner still calls Free
end;

begin
  Sock := TSocket.Create;
  Sock.Close;
  FreeAndNil(Sock);   // the only free
end;
```

## Rationale

A `Close` that destroys its own instance breaks the ownership model, and `Free`
is not idempotent, so the heap is corrupted far from the mistake.

## Silencing it

`{@allow(P0502, reason: "...")}` should be rare: stop freeing in the method, or
use `FreeAndNil` so a repeat free is a no-op.
