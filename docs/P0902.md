# P0902: todo-marker

A `Todo()` or `Unreachable()` call is present in shipping code. The
`rustlike.pas` helpers raise at the call site with `file:line`, so a marker on a
reachable path is a guaranteed crash rather than a note.

## Failing example

```pascal
procedure HandleCommand(const Line: string);
begin
  if Line = 'quit' then
    exit;
  Todo('handle the remaining commands');   // raises when reached
end;
```

## Fixed example

```pascal
procedure HandleCommand(const Line: string);
begin
  if Line = 'quit' then
    exit;
  WriteLn('unknown command: ', Line);
  ExitCode := 2;
end;
```

## Rationale

A reachable `Todo` converts an unfinished feature into a runtime abort, so the
failure depends on user input rather than on the build. It is a warning because
markers are legitimate while work is in progress, and the spec's agent loop ends
with a clean check. The call is syntactic, so false positives are essentially
nil.

## Silencing it

`{@allow(P0902, reason: "...")}` is legitimate for a branch that is provably
unreachable in this build and tracked by an issue. Otherwise implement the path,
or replace the marker with an error the caller can handle.
