# P0901: public-unused-externally

A symbol in a unit's `interface` section is never referenced from outside that
unit. The public surface is larger than what any caller actually uses.

## Failing example

```pascal
interface

function TokenCount(const Text: string): Integer;
procedure DebugDump(const Text: string);   // nothing outside uses this
```

## Fixed example

```pascal
interface

function TokenCount(const Text: string): Integer;

implementation
// DebugDump removed: nothing outside the unit referenced it
```

## Rationale

Every exported symbol is a promise: it must be documented, kept working, and
considered before any refactor. `DebugDump` is exported but unreachable, so it
costs maintenance and advertises an API that does not exist. It is `allow` by
default because a library's intended surface is a design decision, and false
positives are expected in library roots.

## Silencing it

`{@allow(P0901, reason: "...")}` is legitimate for symbols that are part of the
unit's published API or consumed outside the analyzed project. Otherwise move the
symbol to `implementation`, or delete it.
