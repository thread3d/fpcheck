# P0103: unused-binding

A binding is declared and never used: a local, parameter, private field, private
routine, or a unit in the `uses` clause. FPC reports several of these as hints or
notes; P0103 collects them under one code.

## Failing example

```pascal
function Sum(const Values: array of Integer): Integer;
var
  I: Integer;
  UnitName: string;   // never referenced
begin
  Result := 0;
  for I := Low(Values) to High(Values) do
    Inc(Result, Values[I]);
end;
```

## Fixed example

```pascal
function Sum(const Values: array of Integer): Integer;
var
  I: Integer;
begin
  Result := 0;
  for I := Low(Values) to High(Values) do
    Inc(Result, Values[I]);
end;
```

## Rationale

An unused binding is either dead weight or the residue of a half-finished edit,
and the second is exactly what an agent leaves behind. It is a warning because
callback parameters are sometimes forced by a signature and a unit is sometimes
kept only for its initialisation section.

## Silencing it

`{@allow(P0103, reason: "...")}` is legitimate for a signature-forced parameter.
The cheaper alternative is to prefix the name with `_`, which records the intent
at the declaration itself.
