# P0702: with-statement

`with` is banned outright. It makes name resolution depend on the type of an
expression, so a reader — or an agent editing nearby code — cannot tell which
record or object a bare identifier refers to.

## Failing example

```pascal
with P do
begin
  Inc(X);
  Inc(Y);
end;
```

## Fixed example

```pascal
Inc(P.X);
Inc(P.Y);
```

## Rationale

Inside the `with`, `X` could be a field of `P`, a local, a unit-level variable,
or a symbol from another unit — and adding a field elsewhere can silently change
which one wins. The spec bans it because that ambiguity is corrosive for
LLM-generated edits, where every identifier should have one visible meaning. The
construct is syntactic, so there is no false-positive risk.

## Silencing it

There is no legitimate suppression, so `{@allow(P0702, ...)}` should not appear
in a codebase. Bind the target to a local and write `local.Field`, which is also
shorter to read.
