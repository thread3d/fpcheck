# P0801: empty-except

An `except` block that handles nothing: no recovery, no logging, no re-raise. The
exception disappears and the program continues as if the operation succeeded.

## Failing example

```pascal
procedure SaveState(const Path: string);
begin
  try
    WriteStateFile(Path);
  except
  end;   // every failure disappears here
end;
```

## Fixed example

```pascal
procedure SaveState(const Path: string);
begin
  try
    WriteStateFile(Path);
  except
    on E: Exception do
      WriteLn(ErrOutput, 'state not saved: ', E.Message);
  end;
end;
```

## Rationale

The caller is told the state was saved after a failure that left no file, and
nothing anywhere records why — silent swallowing is the most effective way to
turn a fast failure into an unexplained one. It is an error because an empty
handler has no reading under which it is correct. The handler is empty by
construction, so there is no flow reasoning to get wrong.

## Silencing it

`{@allow(P0801, reason: "...")}` is legitimate for a shutdown path where nothing
can be recovered and logging is impossible — the spec's own example. Prefer at
minimum a comment and a log call over an empty block.
