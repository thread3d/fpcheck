# P0802: catch-all-except

A bare `except` or `on E: Exception` handler that neither re-raises nor logs.
Unlike P0801 the block is not empty — it is just too broad, and it hides failures
the caller needed to see.

## Failing example

```pascal
try
  Update;
except
  on E: Exception do
    WriteLn(E.Message);   // caught, logged, never re-raised
end;
```

## Fixed example

```pascal
try
  Update;
except
  on E: Exception do
  begin
    WriteLn(ErrOutput, E.Message);
    raise;   // the caller decides what to do
  end;
end;
```

## Rationale

Catching `Exception` claims this routine can handle anything, which is almost
never true: a programming error such as an access violation becomes a log line
and the program continues with corrupt state. It is a warning because top-level
entry points legitimately catch everything, and those handlers are exactly the
false-positive risk.

## Silencing it

`{@allow(P0802, reason: "...")}` is legitimate at a process or thread boundary
where a hard crash is the only alternative. Inside normal routines, catch the
specific exception classes you can act on, or re-raise.
