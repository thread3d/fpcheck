# P0704: unchecked-hard-cast

A hard typecast reinterprets a value between types of different size, or between
managed and unmanaged types. Nothing is converted — the bits are relabelled.

## Failing example

```pascal
function AsPointer(const Value: Integer): Pointer;
begin
  Result := Pointer(Value);   // 4-byte value relabelled as a pointer
end;
```

## Fixed example

```pascal
function AsPointer(const Value: PtrInt): Pointer;
begin
  Result := Pointer(Value);   // sign-correct size on every target
end;
```

## Rationale

`Integer` is 32 bits and a pointer is 64 on the usual targets, so the cast
silently drops or sign-extends half the value — and on a 32-bit target the same
code happens to work, which is how it survives review. Using `PtrInt` makes the
width follow the platform. The false-positive risk is on equal-size casts between
unmanaged types.

## Silencing it

`{@allow(P0704, reason: "...")}` is legitimate only when the bit pattern is the
point, and that belongs in an `{@unsafe(reason: "...")}` region instead.
Otherwise use a converting cast when the types are compatible.
