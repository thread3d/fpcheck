# P0504: free-of-borrowed

`Free` is called on a value marked `{@borrowed}` — a parameter, a `{@weak}`
field, or a borrowing accessor's result. Ownership belongs to someone else, so
freeing it here is a double free waiting to happen.

## Failing example

```pascal
procedure Log(const Line: string; {@borrowed} Logger: TLogger);
begin
  Logger.WriteLine(Line);
  Logger.Free;   // the caller still owns Logger
end;
```

## Fixed example

```pascal
procedure Log(const Line: string; {@borrowed} Logger: TLogger);
begin
  Logger.WriteLine(Line);
end;
```

## Rationale

`Log` releases an object it does not own, so the caller frees it again — a double
free that triggers only when `Log` is called. Class-typed parameters default to
`{@borrowed}` in `strict` units, which makes this catchable without annotating
every call site. The annotation is explicit, so false positives are unlikely.

## Silencing it

Delete the `Free`. If the routine really does take ownership, change the contract
to `{@owned}` or `{@sink}` and make the caller stop freeing;
`{@allow(P0504, ...)}` with an unchanged signature means the annotation and the
code still disagree.
