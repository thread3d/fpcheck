# P0001: allow-without-reason

Every suppression must state *why* the diagnostic does not apply. An
`{@allow(...)}` without `reason:` is itself an error, so escape hatches stay
auditable.

## Failing example

```pascal
procedure LoadConfig(const Path: string);
begin
  try
    ReadConfig(Path);
  except
    {@allow(P0801)}
  end;
end;
```

## Fixed example

```pascal
procedure LoadConfig(const Path: string);
begin
  try
    ReadConfig(Path);
  except
    {@allow(P0801, reason: "a missing config file is expected on first run")}
  end;
end;
```

## Rationale

An unexplained suppression is indistinguishable from an attempt to hide a real
bug, and it tells the next reader nothing about whether the diagnostic was
understood in the first place.

## Silencing it

There is nothing to silence: write `{@allow(P0801, reason: "...")}` with a real
justification. `fpcheck check --report-allows` lists every suppression.
