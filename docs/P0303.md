# P0303: constant-out-of-range

Both sides of an assignment are known at compile time and the constant does not
fit the target type. This is the subset of range violations that can be decided
before the program runs.

## Failing example

```pascal
const
  MaxRetries = 300;
var
  Retries: Byte;
begin
  Retries := MaxRetries;   // 300 does not fit in a Byte
```

## Fixed example

```pascal
const
  MaxRetries = 300;
var
  Retries: Word;
begin
  Retries := MaxRetries;
```

## Rationale

FPC rejects this with "range check error while evaluating constants (300 must be
between 0 and 255)", but only when range checking is enabled. Widening `Retries`
preserves the intended limit of 300; shrinking the constant would change
behaviour. False positives are essentially impossible, because no path-dependent
reasoning is involved.

## Silencing it

There is no legitimate suppression, so `{@allow(P0303, ...)}` should not appear.
Widen the target type, or correct the constant if the limit itself was wrong.
