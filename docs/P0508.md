# P0508: ownership-escape

A local `{@owned}` value is stored into a longer-lived location — a global, a
field, or a container that outlives the routine — without an explicit transfer.
Two owners now believe they hold the same object.

## Failing example

```pascal
procedure Publish;
var
  Report: TReport;
begin
  Report := TReport.Create;
  GPublished := Report;   // escapes; Report is still the local owner
end;
```

## Fixed example

```pascal
procedure Publish;
var
  Report: TReport;
begin
  Report := TReport.Create;
  try
    GPublished := Report;
    Report := nil;   // ownership transferred to GPublished
  finally
    Report.Free;     // runs only if the transfer did not happen
  end;
end;
```

## Rationale

Both the local and the global look like owners: whoever frees first leaves the
other dangling, and if neither does the object leaks — with no reader able to
tell which was intended.

## Silencing it

`{@allow(P0508, reason: "...")}` is legitimate when the destination does not take
ownership and the local still frees the value. Prefer an explicit `{@sink}`.
