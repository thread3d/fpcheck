# P0203: variant-tag-mismatch

A variant record's field is read without establishing that the tag selects that
field's arm. The bytes read belong to a different variant.

## Failing example

```pascal
function Area(const Shape: TShape): Double;
begin
  Result := Pi * Sqr(Shape.Radius);   // Kind is never checked
end;
```

## Fixed example

```pascal
function Area(const Shape: TShape): Double;
begin
  case Shape.Kind of
    skCircle: Result := Pi * Sqr(Shape.Radius);
    skRect: Result := Shape.Width * Shape.Height;
  end;
end;
```

## Rationale

`Radius` shares storage with `Width`, so the failing call computes a circle area
from a rectangle's bit pattern — a plausible-looking wrong number, the worst
kind. It is flow-sensitive: `if Shape.Kind = skCircle then` narrows the tag and
silences the diagnostic, so the risk is on tags set through a pointer.

## Silencing it

`{@allow(P0203, reason: "...")}` is legitimate only for deliberate
reinterpretation, which belongs in an `{@unsafe}` region instead. Otherwise
branch on the tag before reading the field.
